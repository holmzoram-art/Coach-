## Merk

Hevy synker også til Strava, så **enkeltøkter** finnes allerede der med full
øvelsesliste i beskrivelsen. Denne fila er verdifull av én grunn: den gir
**historikken bakover**, to år før Strava-dataen vi jobber med.

Les fila med script. Ikke last den inn som tekst.

## Hentemetode

Hevy → Innstillinger → Eksporter data. Ny eksport ca. hver tredje måned.
